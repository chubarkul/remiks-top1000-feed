# Remiks — top-1000 feed

Топ-1000 товаров remiks.com по продажам за 7 дней (Метрика, counter 95364845, 18–24.09.2026).
В фиде 958 товаров — столько из топ-1000 присутствует в исходном фиде клиента, для каждого есть картинка в images/.

- feed.xml — Google Merchant RSS, ссылка для AIR
- feed.csv — тот же набор в исходном facebook-формате
- images/<id>.jpg — картинки, имя файла = id товара
- build_feed.py — сборка feed.xml из feed.csv
